# First Blog

A simple blog application built with React and Express.js.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Express.js, PostgreSQL (Supabase)
- **Authentication**: JWT

## Quick Start

1. Install dependencies
   ```bash
   npm install
   cd server && npm install
   ```

2. Create `.env` files with your Supabase credentials

3. Start the application
   ```bash
   # Frontend
   npm run dev
   
   # Backend
   cd server && npm start
   ```

## Features

- User authentication (login/register)
- Blog post viewing
- Responsive design
- Admin dashboard
